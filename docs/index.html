Built for Speed

Everything Laravel & PHP developers need on Windows

Portable official binaries, zero container overhead, and instant per-project configuration.

PHP

Multi-Version PHP & FastCGI

Run PHP 8.0 through 8.5+ simultaneously on dedicated loopback FastCGI ports (9180–9185), edit php.ini, toggle extensions & Xdebug, and use php/composer PATH shims.

JS

Node.js LTS & CLI Shims

Install and switch Node.js 18, 20, 22, 24, and 26 LTS per project or globally, with automatic node, npm, and npx batch shims in your Windows PATH.

*.test

Nginx & Automatic *.test Domains

Scans your parked project folders, generates Nginx virtual hosts automatically, syncs Windows hosts entries, and flushes DNS in one click.

TLS

Zero-Config Local HTTPS (mkcert)

Installs a trusted Windows Root CA and generates wildcard *.test TLS certificates via mkcert so every local Laravel site runs smoothly over HTTPS.

CLI

Laravel Scaffolding & Inspector

5-step project creation wizard, artisan about diagnostics, maintenance mode toggle, cache clear/optimize, storage:link, Composer installer, and live laravel.log viewer.

URL

Cloudflare & Ngrok Tunnels

Expose any local site over a public HTTPS URL with one click using cloudflared or Ngrok v3, complete with real-time request logs and ping checks.

Clean & Isolated

Zero system clutter. Everything stays in one directory.

LaraTool stores binaries, configs, SSL certs, databases, and logs neatly under %USERPROFILE%\.config\laratool\—leaving your Windows system clean. 

%USERPROFILE%\.config\laratool\
├── config.json   # Parked paths, ports, default PHP & Node
├── bin\          # PATH shims (php.bat, composer.bat, node.bat, npm.bat)
│                 # + composer.phar, mkcert.exe, ngrok.exe, cloudflared.exe
├── php\          # Isolated PHP runtimes (php-8.0 ... php-8.5+)
├── nodejs\       # Isolated Node.js runtimes (node-18 ... node-26)
├── nginx\        # Nginx Win32 + conf/conf.d/*.conf virtual hosts
├── servers\      # MariaDB, PostgreSQL, Redis, Meilisearch, Mailpit...
├── data\         # Persistent database & search data directories
├── ssl\          # mkcert wildcard *.test certificates
└── logs\         # App, Nginx, PHP FastCGI, and service logs
